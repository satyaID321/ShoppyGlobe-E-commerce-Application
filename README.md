About ShoppyGlobe Application

ShoppyGlobe is a responsive e-commerce web application built with React and Redux Toolkit. It allows users to browse products, view detailed product information, search products in real time, manage a shopping cart with quantity controls, and place orders through a simple checkout flow. The application uses API-based product data, lazy loading, code splitting, and localStorage persistence to ensure good performance and user experience across devices including 404 Not Found page for invalid routes.

This is a simple React application created using **Vite**.  
Vite provides fast development with Hot Module Replacement (HMR).

## 🚀 Getting Started

### Prerequisites
- Node.js (v16+ recommended)

```bash
